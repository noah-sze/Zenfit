表頭「缺少邊距 vs 行高過高」設計難題解法

UI/UX Pro Max

解析厚膠囊造成結構擠壓的根本原因，提供 4 種優雅兼顧「呼吸留白」與「精緻行高」的專家解法

⚡ 設計難題核心本質 (The Core Conflict)
• 厚重膠囊的雙層嵌套開銷：傳統 Capsule 是「容器外邊框 + 容器 Padding + 按鈕內邊框 + 按鈕 Padding」，光是裝飾外殼就吃掉 12px~14px 的高度。
• 矛盾點：若表頭維持精緻的 32px~36px，按鈕上下就幾乎零留白（貼頂貼底）；若為了留白把表頭撐到 44px~48px，表頭又會變得過高、笨重，搶走下方內容焦點。
• 解法核心：輕量化按鈕結構，降低內部嵌套層次，讓高度自然釋放給「上下呼吸邊距 (Breathing Room)」。
方案 1

精密微型無框滑塊 (首選推薦)

上下留白充裕 · 行高克制

行高維持精緻的 36px (h-9)；切換器去掉外層厚邊框，改為純內嵌微滑塊（高度 24px），上下擁有均勻舒適的 6px 留白呼吸感，完美平衡。

方案 2

純文字極簡分段器 (Vercel Style)

零膠囊 · 最扁平

徹底告別膠囊！採用 Vercel / GitHub 經典的文字切換，選中項加粗純黑，未選中項為淺灰，行高即便在 32px (h-8) 依然上下透氣。
